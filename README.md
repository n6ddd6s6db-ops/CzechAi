Experimenting with AI: Small steps toward a bigger goal.
A custom macOS voice & text AI assistant built on a client-server SaaS architecture.
Developed using an AI-assisted development (AI pair programming) workflow to rapidly translate architectural concepts into a functional prototype while gaining hands-on experience in system integration, backend security, and end-to-end testing.
• Backend & Auth: Python, FastAPI, SQLAlchemy (SQLite), secure user authentication via JWT tokens and Bcrypt password hashing.
• AI & Security: Server-side API endpoints for OpenAI (LLM, Whisper STT, TTS), keeping sensitive API keys completely isolated from the client application.
• Client & Web: Native macOS .app bundle (CustomTkinter) capable of executing macOS system commands, paired with a dark-themed web portal for user registration and login.
